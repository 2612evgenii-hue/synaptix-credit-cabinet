# Проверка frontend — 21.10.2026

Область: `apps/web`, локальный Chrome, Node 22.22.2 / npm 10.9.7, macOS.
Это проверка UI и браузерного демо-состояния, не E2E банковского backend.

## Автоматические проверки

- `npm test --prefix apps/web`: 7 тестов. Аннуитет проверен на 80 сочетаниях
  суммы/срока/ставки, сверены копейки основного долга и процентов, конечный остаток.
- Проверены NaN/Infinity, дробный/нулевой срок, отрицательная ставка; пустые поля
  отличены от нуля; неполный черновик и роль бухгалтера не могут отправить заявку.
- Проверены последовательность решение → подпись → готовность → выдача,
  ограничения ролей, несовпадение подписанной версии, повторная выдача,
  отказ и дозапрос, единый генератор документа для линии.
- `npm run build --prefix apps/web`: строгая проверка TypeScript и Vite production build.
- `npm audit`: 0 известных уязвимостей на момент проверки. npm сообщает peer warning
  о вложенном react-virtual из неиспользуемого Alfa Select; импортируемые элементы
  проверены в React 18.3.1. Это не гарантия отсутствия неизвестных уязвимостей.

## Фактически пройдено через интерфейс

- Калькулятор → новая заявка АК-1049 на 2 млн → пять шагов → сохранение после reload.
- Финансы из синтетического набора, демо-выписка, подтверждение и отправка.
- Смена роли → та же заявка в очереди → назначение сотрудника → запрос сведений.
- Клиент видит запрос; пустой ответ заблокирован; комментарий возвращает заявку в review.
- Имитация сбоя источника отключает подтверждение проверки, статус заявки не становится отказом.
- Предложение с изменением только ставки 16 → 17% помечено «Другие условия»;
  старая/новая ставка, проценты и общая сумма выплат видны до подписи.
- Подпись версии 2 → отдельное подтверждение готовности сотрудником → отдельная выдача.
- После частичного погашения 100 тыс. остаток 1,9 млн и платёж 93 940 ₽ сохранились после reload.
- Сброс из UI восстанавливает синтетический набор с черновиком, заявкой в очереди,
  действующим кредитом и кредитной линией; реальные данные не использовались.
- Новый транш: превышение лимита блокирует действие; 500 тыс. в линии с долгом
  700 тыс. увеличивает долг до 1,2 млн и уменьшает доступный лимит до 1,8 млн.

- После полного погашения двух траншей долг стал 0 ₽, доступный лимит — 3 млн ₽,
  линия осталась открытой. Отдельное закрытие убрало выдачу и обнулило доступный лимит.
- Обращение клиента появилось сотруднику; его ответ сохранился с состоянием «Есть ответ».
- Проверена загрузка production-сборки через Vite preview, вместо HMR/dev.

## Ограничения проверки

- Docker Engine недоступен (`/var/run/docker.sock` отсутствует), Compose v2 отсутствует.
  Поэтому image build / container health / restart не объявляются проверенными.
  Образы node:22.22.2-alpine и nginx:1.28.0-alpine существуют — remote manifest получен.
- Не проверены Safari/Firefox, реальные устройства, screen reader и полный WCAG-аудит.
- Нет внешнего API: сетевые сбои API, сессии, конкурентные транзакции и юридическая
  подпись не могут быть доказаны этой проверкой. localStorage не заменяет сервер.
- Нужны независимое ревью и финальная визуальная приёмка владельца.
