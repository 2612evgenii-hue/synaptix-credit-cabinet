# Сценарии проверки

20 сценариев на 2026-10-20. Столбцы «Фактический результат» пустые: сайта нет.
Повторять шаги может другой человек без устных пояснений. Где поведение зависит от ещё не принятого правила, в ожидании стоит вопрос.

Общие условия, пока нет инструкции запуска:

- Вход — тестовый клиент из принятой инструкции. Логины из невлитого PR не использовать.
- Суммы ниже — то, что человек вводит на экране, в рублях.
- Названия кнопок в продукте ещё не согласованы. Искать действие по смыслу: сохранить, отправить, открыть заявку.
- Ожидаемое кредитное решение (одобрить, отказать, предложить другие условия) не фиксируется, пока его не подтвердит Пётр.
