# Сценарии приёмки MVP

Статус: **план**, ни один сценарий продукта ещё не выполнен. При реализации
указать команду автоматического запуска, SHA, дату, окружение и результат.

| ID | Действие | Ожидаемое доказательство |
| --- | --- | --- |
| E2E-01 | Чистый клон → единая Docker-команда | Все сервисы healthy, веб/API доступны без платных ключей |
| E2E-02 | Выбрать продукт → черновик → обновить страницу | Введённые поля сохранены |
| E2E-03 | Отправить → проверки → оценка → решение → принятие | Последовательные статусы и объяснение следующих шагов |
| E2E-04 | Неполная заявка → запрос банка → дополнение | Возврат к обработке без потери данных |
| E2E-05 | Негативные синтетические факторы | Отказ с понятной причиной, без имитации выдачи |
| E2E-06 | Банк предлагает иной срок/сумму | Клиент видит различия и явно принимает предложение |
| E2E-07 | Повторная отправка и две вкладки | Нет двойной заявки/решения; conflict корректно обработан |
| E2E-08 | Customer читает чужой ID / вызывает bank endpoint | 403/404, чужие данные не раскрыты |
| E2E-09 | Рестарт контейнеров | Заявка, решение и события сохранены |
| E2E-10 | Mock timeout/error → повтор | Нет автоматического approve, нет дублирования событий |
| E2E-11 | Просмотр событий/новостей двух синтетических клиентов | Персонализация по контексту, без утечки между клиентами |
| E2E-12 | Принять условия → имитация подписи/выдачи | Явная пометка «демонстрация», нет реальных операций |
| E2E-13 | Проверка OpenAPI / коллекции | Сервер соответствует контракту, запросы исполнимы |
| E2E-14 | Поиск секретов и просмотр seed | Только синтетические данные, история без найденных секретов |

Юнит-тесты продукта: допустимые/запрещённые переходы, граничные суммы/сроки,
отдельные расчёт риска и кредитное решение, RBAC, идемпотентность.
Интеграционные: транзакция состояние+аудит, миграции+seed, persistence и mock failure.
Тесты в `tests/governance` проверяют только инструменты репозитория.
