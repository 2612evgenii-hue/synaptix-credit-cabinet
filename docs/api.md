# Проект API

Машиночитаемый **черновик**: [OpenAPI](../packages/contracts/openapi.json).
[Коллекция Postman](api/postman_collection.json) использует `baseUrl` и `token`.
API ещё не реализовано; коллекция сейчас не подтверждает работоспособность сервера.

План API: сессия демонстрационного пользователя, каталог продуктов, создание и
чтение заявок, отправка, получение событий, банковское решение. Перед реализацией
добавить уточнение данных/документы, альтернативные условия и имитацию выдачи.
Обновлять контракт и тесты совместно, не подменять изменения сервера только документацией.

UUID, `Authorization: Bearer`, JSON; суммы в копейках. Idempotency-Key — для
изменяющих операций. Версия заявки — для защиты от конкурирующих обновлений.
Ошибка содержит `code`, безопасное `message`, `correlationId`; стандартные 400/401/403/404/409/422/500.
Customer видит только свою компанию. Bank видит заявки в пределах разрешённой роли.
Входные DTO с явной валидацией; клиент не задаёт decision/score/роль/created_by.
