# Проверка каркаса репозитория

Дата: 2026-10-20. Это проверка организации разработки, не готовности приложения.

- `make check`: policy и тесты коммитов/веток/ролей, fail-closed сдачи и проверки
  реальных настроек защиты. Проверены случаи отключённой защиты, неверного источника
  CI check, сброса ревью, подмены пути evidence и отсутствия дедлайна.
- Gitleaks 8.30.1: скан текущих файлов и доступной истории без находок.
- [Первый успешный GitHub Actions run](https://github.com/2612evgenii-hue/synaptix-credit-cabinet/actions/runs/39427818501):
  `repository-policy` и `secret-scan`, commit `470246952124ff1876f9fefc8ad6b3ab4e56f97a`.
- `scripts/export_audit.py`: сформирован локальный JSON/Markdown журнал Git.
- `scripts/backup.py`: создан bundle и успешно выполнен `git bundle verify`.
- `submission_check.py`: ожидаемо отклоняет каркас без Docker, E2E, точного дедлайна
  и остальных доказательств реализации.
- `freeze.py`: отказывается создавать manifest для прошедшего дедлайна.
- GitHub API подтвердил приглашения двух участников, режим squash-only,
  default token read без права approve и public visibility после решения владельца.
- Повторный Gitleaks обнаружил временный clone token в локальном ignored экспорте
  GitHub API. Поля credentials теперь удаляются при экспорте, добавлен тест,
  локальный отчёт пересоздан. Токен не добавлялся в Git и не публиковался.

Выходы скриптов лежат в ignored `artifacts/`; их надо отдельно архивировать.
Финальные результаты защиты main и попытки прямого обновления сохраняются в
[Issue #1](https://github.com/2612evgenii-hue/synaptix-credit-cabinet/issues/1)
после bootstrap, чтобы не обходить независимое ревью для правки самого отчёта.

Ограничения: 2FA участников не проверена; приглашения могут ожидать принятия;
стек/приложение не созданы. Docker CLI установлен, но daemon на этом Mac во время
проверки был недоступен. Прикладной Docker/E2E-запуск не выполнялся.


21.10.2026: frontend реализован отдельно; фактическое покрытие и ограничения
описаны в [протоколе frontend](frontend-verification.md). Утверждения выше относятся
к каркасу на 20.10.2026, не к текущему состоянию веб-интерфейса.
