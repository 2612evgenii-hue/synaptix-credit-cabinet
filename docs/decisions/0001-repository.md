# ADR-0001: один монорепозиторий и интеграция через main

Дата: 2026-10-20. Статус: принято для каркаса репозитория.

Команда из трёх участников должна интегрировать единый кредитный путь и представить
однозначную версию решения. Выбраны private monorepo, `main`, короткие рабочие ветки,
один независимый reviewer, squash и SemVer. Главный администратор — владелец.

Это позволяет менять API и клиент в одном PR, запускать общие проверки и фиксировать
весь продукт одним SHA. Отдельные репозитории/долгая develop добавят координацию
без текущей необходимости. Цена решения — необходимость согласовать зоны файлов.

Стек продукта ещё не выбран. GitHub Organization предпочтительна при необходимости
read-only collaborator, принудительной 2FA и расширенного аудита. Приватность
не меняется автоматически ради доступности защиты на бесплатном тарифе.
