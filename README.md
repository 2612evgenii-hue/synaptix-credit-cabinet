# SYNAPTIX · Умный кредитный кабинет

Команда **SYNAPTIX**, Альфа Хакатон 2026. Проект цифрового кредитного
конвейера для малого и микробизнеса: от выбора финансирования до результата
по заявке, с клиентским веб-кабинетом и рабочим местом банка.

**Текущий этап:** подготовка репозитория. Прикладной прототип пока не реализован.
Зелёный Repository CI означает исправность правил и инструментов репозитория;
он не подтверждает готовность кредитного продукта к сдаче.

## Начать работу

1. Принять приглашение GitHub и включить 2FA в своём аккаунте.
2. Клонировать репозиторий и настроить локальные проверки:

   ```sh
   git clone https://github.com/2612evgenii-hue/synaptix-credit-cabinet.git
   cd synaptix-credit-cabinet
   python3 scripts/bootstrap.py
   python3 scripts/repo_checks.py
   python3 -m unittest discover -s tests/governance -v
   ```

3. Выбрать Issue, назначить себя и создать ветку `feat/<issue>-<topic>`.
4. Изменения передавать в `main` через Pull Request и ревью коллеги.

Для служебных изменений агента применяется префикс `codex/`.
Правила и примеры: [CONTRIBUTING.md](CONTRIBUTING.md).

## Окружение и проверки

Инструменты репозитория: Python **3.12.12**, Git 2.39+, GitHub CLI 2. GitHub CI
фиксирует Python через `.python-version`. Дополнительные Python-библиотеки не нужны.
Внешние Actions закреплены SHA; Gitleaks 8.30.1 скачивается с проверкой SHA-256.
Для проверки секретов локально: `gitleaks git --redact --log-opts="--all"`.
Для приложения ещё предстоит выбрать версии языка, библиотек и Docker-образов,
добавить lock-файлы и единый `docker compose up --build`.

```sh
make check          # политика репозитория + тесты инструментов
make audit          # локальный журнал Git в artifacts/audit/
make github-audit   # прочитать фактические настройки GitHub
make backup         # Git bundle + SHA-256 в artifacts/backups/
make submission-check  # сейчас ожидаемо НЕ проходит: прототип ещё не создан
```

Дата дедлайна пока неизвестна. Не выдавайте текущий каркас за сдаваемое решение.
Перед сдачей нужен полный запуск на чистом ПК, end-to-end-проверка и неизменяемая
ссылка на версию. Условия исходного кейса не устанавливают название репозитория
или обязательный стек: выбран один публичный монорепозиторий для трёх участников.
Публичность включена по явному решению владельца для бесплатной серверной защиты.
