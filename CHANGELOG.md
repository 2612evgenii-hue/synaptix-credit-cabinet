## [Unreleased]

### Added

- Локальный React-фронтенд кредитного кабинета: клиент, бухгалтер и сотрудник банка,
  сохранение демо-сценария, расчёт, заявка, решение, подпись, выдача и обслуживание.
- Alfa Core Components, три сгенерированные иллюстрации, адаптивные блочные экраны.
- Доменные проверки frontend, Docker-конфигурация и отдельный протокол проверки.

- Разбор 12 предоставленных изображений мобильного банкинга: компоненты,
  растровая геометрия и визуальные состояния без публикации исходных личных экранов.
- Исследование визуальных систем Альфа-Банка: desktop/mobile замеры,
  публичные токены, скриншоты, реестр покрытия и инструкции для SYNAPTIX.
- Каркас публичного монорепозитория SYNAPTIX для трёх участников.
- Матрица требований кейса, план MVP, проект API и схемы.
- Правила коммитов, PR, доступа, версий, резервирования и сдачи.
- CI, поиск секретов по истории, локальные hooks, экспорт Git/GitHub и Git bundle.
- Публичность по решению владельца; профили серверной защиты main и релизных тегов.

Backend-интеграция и E2E полного продукта ещё не реализованы. Docker-конфигурация
frontend добавлена; исполнение контейнера на этом Mac не подтверждено.
